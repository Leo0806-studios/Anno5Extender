Storage cap extender for anno2070
this plugin allows raisign the max storage coap of warehosues in anno2070 above the hardcoded 999

on first launch it will generate a config file in the Anno5Extender/config/Anno5WarehouseStorageCapExtender/config.txt file where you can set the new cap value. The default value is 999999 wich coresponds to the  normal game default
the actual ingame value is config value / 1000
